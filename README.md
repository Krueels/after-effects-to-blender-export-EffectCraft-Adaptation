# After Effects to Blender Export — EffectCraft Adaptation

An adaptation of [adroitwhiz's After Effects to Blender Export](https://github.com/adroitwhiz/after-effects-to-blender-export) for EffectCraft.

Original script by **adroitwhiz**. EffectCraft adaptation by [Krueels](https://github.com/Krueels).

## Requirement

**You must install and enable the original Blender addon before importing the exported JSON file. This adapted JSX script does not replace the Blender addon.**

Get the addon and installation instructions from the [original repository](https://github.com/adroitwhiz/after-effects-to-blender-export).

## Usage

The usage and steps are exactly the same as in the original After Effects workflow. Run the adapted JSX script in EffectCraft instead of After Effects, export your composition data to JSON, and import it into Blender using the original addon.

Follow the [original documentation](https://github.com/adroitwhiz/after-effects-to-blender-export) for the complete workflow and export options.
